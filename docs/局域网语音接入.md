# 局域网语音接入（联调中）

## 当前实现

- `scripts/start-voice.ps1 -BindIp <本机WLAN的IPv4>`准备配置并启动语音服务，默认值仍为回环地址；不修改防火墙。
- `.env`中的`PET_DEVICE_ID`来自三份一致的本机芯片读取记录。设备标识、模型密钥和连接令牌均保留在忽略目录，不提交GitHub。
- OTA POST与WebSocket入口过滤绑定的设备标识及非空Client-ID；WebSocket继续校验上游HMAC令牌。标识过滤不是不可伪造的硬件身份，不将服务映射到公网。
- 固件从忽略的`.runtime/device-endpoint.json`读取`ota_url`，编译为本地生成的`main/pet_endpoint.h`。只接受RFC1918 IPv4、HTTP 8003端口与`/xiaozhi/ota/`路径，不接受用户密码、查询参数或控制字符。该头文件不含模型密钥。
- 本地发现返回的WebSocket资料只写入`pet_ws`命名空间；本地协议也只读取该命名空间。原有`wifi/ota_url`、`websocket`及`mqtt`资料不被这段适配改写。
- 不存在私有端点配置时，生成空覆盖值，恢复读取原固件的服务发现地址与原WebSocket命名空间。原宠物固件或原厂固件回退资料保留。
