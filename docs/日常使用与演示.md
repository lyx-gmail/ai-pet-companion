# 日常使用与面试演示

适用于本项目已适配的三键 ESP32-S3 小方块。下面按屏幕朝向自己时的位置描述。

## 先开始使用

1. 设备连上已配置的 Wi-Fi，进入全屏眼睛。
2. 双击项目根目录 `打开服务监控.vbs`，点击“全部连接”。已配置的记忆、语音服务启动后，窗口会更新状态。
3. 短按中键开始说话；说完等待回应。再次短按中键结束或打断，回到全屏眼睛。

首次在另一台电脑安装，请先按 [首页](../README.md) 和 [语音安装说明](../backend/VOICE.md) 配置依赖、模型及局域网地址。控制面板复用现有配置，不会替你完成首次配置。

## 三个键

| 按键 | 短按 | 长按约 2 秒 |
|---|---|---|
| 左键 | 抚摸 | 静音 / 恢复声音 |
| 中键 | 开始语音；对话中取消 | 打开 / 退出设置 |
| 右键 | 喂食 | 睡眠 / 唤醒 |

睡眠时，第一次短按任意键只唤醒，不直接喂食、抚摸或开麦。对话中请先短按中键结束，再用侧键照顾。

设置中：侧键选择或调整，中键进入或保存；长按中键退出。静音控制扬声器输出，不等于禁麦。

## 记忆怎么用

先说“请记住，叫我小林”，完成确认后，再说“我喜欢天文学”，分别确认称呼与偏好。系统识别为待记忆资料时，会用语音读出待保存内容并提示：中键保存，左键取消；超时自动取消。屏幕保留全屏眼睛，资料可在电脑控制面板查看。请听清待保存内容再确认；未经按键确认，不把口头答应当作已经保存。

结束这一轮，再问“你记得我叫什么，喜欢什么吗？”观察新会话回复。称呼和偏好是稳定资料，关系变淡不会自动清除；经历的降权规则可看 [模拟时间回放](../demo/记忆衰减回放.md)。

## 90 秒演示顺序

1. 展示全屏双眼，短按左键、右键各一次，展示本地照顾反馈。
2. 短按中键问“你现在的饱食度是多少？”让模型读取设备真实状态。
3. 说出虚构称呼和偏好，录下口头确认提示并中键确认。
4. 结束后重开一轮，询问称呼与偏好。
5. 打开电脑中文控制面板，展示记忆资料与服务连接 / 断开。

如果宠物已经饱了或处于冷却，动作可能不加数值；这属于状态规则，演示时说明实际结果即可。拍摄请同时拍到按键和屏幕；不将资源动画或不同轮次剪成虚假的连续成功。

## 用完后

需要停止增强 AI 时，在控制面板点“全部断开”。设备的本地表情和按键养成继续运行，已提交的记忆保留。只关闭控制窗口不会停止后台服务。

## 当前验证范围

[展示入口](../demo/README.md)记录了当前实机收音、ASR、模型状态工具与说话状态的一次运行。该记录不能替代扬声器听感、所有记忆声学分支或最终实机录像。遇到问题只需反馈“操作 → 实际表现 → 希望的表现”，无需自行运行测试脚本。
