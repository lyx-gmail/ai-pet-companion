# AI 宠物服务控制面板

双击桌面的“AI宠物控制面板”，或项目根目录的 `打开服务监控.vbs`，打开原生 Windows 中文窗口，无需安装新软件。窗口每 2 秒发起一次后台检测，网络超时后可能略有延迟。

- 记忆服务：检查本机 `/health`，显示在线状态、模型是否配置。
- 已确认记忆：通过已有认证接口只读展示称呼、最多四项偏好和资料版本；服务或认证失败时清空旧展示。
- 语音后端：读取 Windows TCP 表，显示 8000/8003 监听与 8000 已建立连接数。连接数属于 TCP 层，不代表认证、收音或可听回复成功。
- 活动摘要：读取现有日志尾部，显示固定中文事件分类及时间。不会将密钥、完整对话或设备标识复制到监控窗口。已确认记忆内容仅在本机窗口显示，不写入新的监控日志。
- 资料版本更新会增加一条本次窗口运行期间的更新提示；详细记忆内容更正、删除仍使用项目原有流程。

每项服务右侧都有“连接 / 断开”，下方也提供“全部连接 / 全部断开”。连接会启动对应本地服务；已运行时复用现有进程。全部连接先启动记忆，再启动语音；全部断开顺序相反。断开会结束正在进行的语音或记忆请求，已提交的记忆保留。

仅管理本项目路径、启动命令均匹配的 Node / Python 服务。端口被其他程序占用时保留它并报错。语音重连沿用既有配置里的局域网绑定地址，再由原启动脚本验证；不会擅自换成回环地址。

关闭窗口不会中断宠物，需点“全部断开”才能停止服务。不会添加开机启动，不修改防火墙，状态检测不进行模型调用。连接后宠物本身可能恢复对话并按原设置调用模型。

启动失败可查看 `.runtime/service-control/` 中的私有启动日志，或语音日志目录；这些原始日志可能包含对话及设备信息，请勿直接上传。

服务未运行时，先在项目目录分别运行 `scripts/start.ps1` 和 `scripts/start-voice.ps1 -BindIp <本机局域网IPv4>`。设备使用本地语音时，语音绑定地址应与设备端点匹配；不要随意改成默认回环地址。

只显示历史活动不代表设备当前仍连接，以实时连接数和最近检测时间为准。日志摘要覆盖最近 64 KiB 中可识别的最后 14 条事件；这不是完整审计或所有记忆召回记录。
