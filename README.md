# AI Pet Companion

一只放在桌面上的 AI 电子宠物。会眨眼、会回应你的照顾，也能通过语音聊天，记住你的称呼和喜好。

## 功能

### 全屏动态表情

极简双眼占满屏幕，支持眨眼、视线移动和情绪变化。抚摸、进食、睡眠与语音交互都有对应的表情反馈，日常界面只保留宠物的脸。

### 喂食、抚摸与陪伴

通过实体按键喂食、抚摸、哄它睡觉。饱食、心情、精力和亲密度随照顾与时间变化，状态自动保存。互动频率影响关系，久未陪伴会逐渐疏远，重新相处也能慢慢亲近。

### AI 语音互动

按下中键即可说话，支持日常聊天、查询宠物状态和语音照顾。问它“你现在饿不饿”，AI 会读取实际饱食状态；也可以直接说“喂你吃点东西”。

### 记住你的称呼和喜好

告诉它“叫我小林”，再告诉它“我喜欢天文”，分别确认后即可在后续对话中使用这些资料。支持记忆更正与删除；稳定的称呼、偏好与逐渐淡化的经历分开管理。

新增记忆通过语音提示确认：中键保存、左键取消，超时自动取消；屏幕始终保留动态双眼，记忆内容可在电脑后台查看。

### 离线养成

表情、按键照顾和养成状态在设备本地运行。电脑后端断开时，仍可喂食、抚摸和睡眠；语音与个人记忆由电脑上的服务提供。

### 中文控制面板

在 Windows 窗口中连接或断开语音、记忆服务，查看运行状态和已确认资料。支持单独控制，也可一键全部连接或断开。

## 按键操作

屏幕朝向自己时：

| 按键 | 短按 | 长按约 2 秒 |
|---|---|---|
| 左键 | 抚摸 | 静音 / 恢复声音 |
| 中键 | 开始语音 / 打断回复 | 打开 / 退出设置 |
| 右键 | 喂食 | 睡眠 / 唤醒 |

睡眠时，短按任意键先唤醒。设置中可调整音量、亮度并管理记忆。
