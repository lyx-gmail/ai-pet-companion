# AI 实体伙伴宠物 · v0.1 预览版

在已购ESP32-S3小智设备上实现全屏眼睛、实体按键养成和可确认、可更正、可删除的个人记忆。第一版重点是记住称呼和少量偏好。设备负责本地交互，电脑负责记忆与模型调用。

**先看[无需硬件的展示入口](demo/README.md)**：真实模型的虚构资料原话、实际设备数值、[记忆衰减回放](demo/记忆衰减回放.md)。实机GIF与完整视频仍待拍摄；[36条验收索引](docs/功能验收证据索引.md)公开列出已验证范围与缺口。

- [实测原始结果](evaluation/live-memory-result.json)：6次模型调用；确认由测试程序触发，未连接实体按键。

- 电脑端语音依赖、官方样本识别、服务模块构造和本机认证/握手已验证；后续真实设备 WebSocket/MCP 连接也已建立，完整声学语音体验仍待验收。见[语音验证说明](backend/VOICE.md)。
- 后续已建立真实设备 WebSocket/MCP 连接，并完成[记忆确认实机联调](docs/记忆确认_实机联调.md)：真实模型草稿在设备确认后保存，取消和超时不保存。测试使用协议调试文本及 USB 按键派发，尚未验证声学 ASR、按键触点和完整听感。
- 原机16MB Flash已备份；全屏RoboEyes固件已实际写入并读回校验，应用之外区域写前、写后校验通过。用户确认双眼会眨眼、转动；左右短按的抚摸、喂食有实机反馈与数值佐证。见[实机记录](docs/实机写入与回退.md)及[构建证据](evaluation/firmware-build.json)。长按、重启保存、新固件语音和实机视频仍待验收。
- 后续V4固件已通过延迟校时与软件重启存档联调：未校时仍能接受照顾，校时后按顺序结算；跨无时钟重启的未知间隔保守冻结，保留已喂食状态。见[范围与证据](docs/离线结算实现.md)，不代表真实拔电故障注入或最终视听验收。
- 无线故障注入发现并修复了断网读取RSSI导致重启的问题。当前镜像停止无线20秒时，语音0.437秒退出等待，离线睡眠/唤醒存盘与恢复连接通过。见[实测与限制](docs/无线断开实机回归.md)；这是设备接口软件暂停，不代表所有路由器/弱信号场景通过。

## 本地启动记忆后端（Windows）

需要Git及网络。项目使用便携Node 22.23.4，不要求替换系统Node。

```powershell
./scripts/setup-memory.ps1
# 在本地 .env 中填写模型服务、模型名和密钥，保留生成的加密密钥和令牌。
./scripts/start.ps1
```

服务监听 `127.0.0.1:8766`，`/health`可查看是否配置模型；其余接口需要本地`PET_API_TOKEN`。双击根目录`打开服务监控.vbs`可在中文窗口连接、断开两项服务，并查看已确认记忆与活动摘要，见[控制面板说明](docs/服务监控使用说明.md)。私人配置、数据库、设备备份和工具目录均不应提交。

```powershell
& ./.tools/node22/node-v22.23.4-win-x64/node.exe --test tests/memory.test.cjs tests/http.test.cjs tests/llm.test.cjs
# 使用可用的Python 3运行：
python -m unittest discover -s tests -p test_voice_memory.py
```

`scripts/live-memory-check.cjs`另行调用真实模型并消耗API额度，使用虚构资料和临时数据库，不修改日常资料。普通测试不调用外部模型。
