# ESP32-S3 实机固件（适配中）

仅适用于档案已确认的`xingzhi-cube-1.54tft-wifi`，不是通用ESP32-S3镜像。源版本与SDK见`toolchain-lock.json`。

```powershell
# 需要Git、Python 3.12和网络；首次安装含SDK与交叉编译工具。
./scripts/setup-firmware.ps1 -Python python
./scripts/build-firmware.ps1
```

构建默认在专用目录 `E:\build\ai-pet` 复制源码运行，解决 Windows GNU 工具链的中文路径限制；原项目仍是编辑源。安装与构建可用同一个 `-BuildRoot` 参数指定其他 ASCII 目录；禁止选择 TEMP 或经重解析父目录转向 TEMP 的位置。工作区 junction 仅建在这个专用目录内，每次构建同步源码，不移动项目。

成功的完整构建将应用复制到项目内 `.tools/firmware-artifacts/xiaozhi.bin`；刷写脚本只从这里读取，并继续核对成功构建记录的长度和 SHA256。`-ConfigureOnly` 不更新镜像。构建脚本不执行刷机、擦除或 eFuse 操作；不得把旧镜像或配置成功当作新构建通过。

当前修改：

- 复用原ST7789、麦克风、扬声器驱动；仅替换目标板显示实例，使用RoboEyes原始运动内核和LVGL矢量绘制适配层。
- 日常状态用黑色不透明全屏画布覆盖状态栏与聊天；启动、激活、配网、升级及故障显示原系统界面。主键长按进入设置，侧键翻页/调整，主键确认；长按退出或30秒超时撤销未确认修改。设置期间暂停语音输入，退出恢复唤醒。
- 裁剪该目标板不用且旧版本不可解析的image_player/emote/旧Otto依赖，未整体升级其余驱动。
- 保留服务器发现、校时与激活；跳过启动时自动下载上游新固件，防止覆盖定制代码。
- `PetRuntime`已接GPIO0语音/只唤醒、GPIO40短按喂食/长按睡眠、GPIO39短按抚摸/长按静音；实物位置与事件行为待验证。长按1500ms、扫描10ms×防抖4次，不注册双击/组合键。
- 状态、计时余数、关系窗口、冷却和静音保存在独立`pet_v1/snapshot`V3版本化92字节blob（含亮度和待睡意图，兼容读取V1的84字节与V2的88字节存档）；动作最迟2秒合并写入、被动变化每5分钟写入，睡眠切换立即提交。校验长度、版本和字段范围；坏档/未来版本/提交错误保留原数据并显示故障页。
- 主脸读取养成状态，短动作结束恢复当前基础脸；睡眠闭眼、降低亮度和刷新。原板型300秒空闲自动深睡已禁用，逻辑睡眠仍计时。全局NVS初始化遇到原先会擦除的错误改为停止启动并输出串口错误，不擦除数据。

`self.pet.get_state`只读MCP工具已注册，返回真实养成值、冷却、睡眠、最近本地事件、revision与持久化/时间状态；坏档时只返回不可用错误，不把初始默认值当已恢复数据。最近事件仅保存在本次运行内存，重启后标为none。已通过实际模型请求在设备读取饱食度；输入是协议调试文本，尚非声学 ASR 验收。

按键已接取消语音后进入设置/睡眠，静音会清理当前对话音频队列；旧回复回调按代次拒绝，编译与补丁重复应用检查通过。尚未实测输入暂停、取消延迟或正在输出的单帧音频尾音。静音仅控制输出；设置期间才暂停语音输入。

已注册self.pet.feed与self.pet.pet，动作编号由语音适配层绑定，按轮次/动作去重；成功动作立即提交存档并返回实际delta与durable。目标编译断言及软件桥接通过，尚无设备调用证据，详见docs/AI动作_实现与验收.md。

self.pet.set_sleep已接保存待睡意图、晚安stop与音频排空后入睡、5秒截止条件和明确唤醒；待睡期间100ms检查，设置页保持前台。真实音频尾音、截止延迟、取消及断电恢复仍未实测。

设备临时记忆确认页已接通，并通过确认保存、取消不保存、超时不保存的实机联调；仍未完成完整的记忆浏览/更正/删除管理页、真实按键触点与睡眠工具体验验收。原记忆管理入口仍如实提示未完成，不展示模拟资料。诊断页仅显示本地状态与时间/存档/音频信息，不显示账号或网络凭据。

时间边界：可信时间到达且尚未发生本地动作时，补未结算关机间隔，生理上限24小时、关系上限7天，回拨不倒算。若动作或5分钟存档早于可信时间，当前代码采用运行时计时并记录日志，省略该次未知关机间隔。**这尚未完全满足详细方案的延后校时补算要求，不能判为通过。**

眼睛内核的源码、版本与完整许可证见`vendor/RoboEyes/`，链接该模块的固件遵守GPL-3.0-or-later。公开演示不得把上游运动算法描述为原创。

新固件编译及实机状态以项目实施记录为准。尚未测实机帧率、音频兼容和恢复；不能直接把浏览器动画预览或编译期断言作为实机验收。
